# VS2026Handbook_Chapter11

A C# project accompanying Chapter 11 of the Visual Studio 2026 Handbook.

## About

This repository contains the chapter's C# sample code and exercises.

## Getting Started

### Prerequisites

- Visual Studio 2026 or a compatible C# development environment
- The appropriate .NET SDK for the project

### Open the project

1. Clone this repository:

   ```bash
   git clone https://github.com/liewvk/VS2026Handbook_Chapter11.git
   ```

2. Open the repository or solution file in Visual Studio.
3. Restore dependencies and build the project.
4. Run the project from Visual Studio.
